ACTCPTools -> bsdsocket.library (ACNet) -> acnet.device -> ACNet card -> Linux HostSocket

- ping: PASS, AmigaOS LoadSeg; integer RTT timing, no double helper dependency
- traceroute: PASS, AmigaOS LoadSeg; integer RTT timing, no double helper dependency
- arp: PASS, AmigaOS LoadSeg; runtime routing API intentionally absent from ACNet core

Live guest results:
- actcp-hostname: RC=0, output: instance-6
- actcp-resolve localhost: RC=0, output: Name: localhost / Address: 127.0.0.1
- actcp-ping 127.0.0.1: RC=1, expected current boundary because ACNet refuses SOCK_RAW

The first two commands used only published bsdsocket.library calls and no ACNet-private interface.
Host ICMP capability check:
- unprivileged AF_INET/SOCK_RAW/IPPROTO_ICMP: EPERM
- unprivileged AF_INET/SOCK_DGRAM/IPPROTO_ICMP: OPEN_OK
- Linux ping_group_range permits the current user group

Implication:
- ping should remain a conventional guest SOCK_RAW/IPPROTO_ICMP client.
- ACNet can virtualise that guest socket using Linux's permitted datagram ICMP socket.
- unrestricted host raw-socket capability is neither required nor desired.
- traceroute should use a normal UDP transmit socket with IP_TTL; ACNet already forwards IP_TTL.
- traceroute still needs a compatible ICMP Time Exceeded receive path.
